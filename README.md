# SwiftUI Playground

A simple iOS application built with SwiftUI to experiment with its features.

## Getting Started

### Prerequisites

Xcode installed.

### How to build and run

1. Clone the repository.
2. Open `SwiftUIPlayground.xcodeproj` in Xcode.
3. Select a simulator or a connected device.
4. Click the "Run" button.
